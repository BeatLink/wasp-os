# Font Awesome Free

`FontAwesome6_Solid.ttf` and `glyphmap.json` are taken from Font Awesome Free 6
(https://fontawesome.com). The font is licensed under SIL OFL 1.1 and the icon
designs under CC BY 4.0.

`gen_app_icons.py` renders glyphs from this font to produce the monochrome app
icons used by the launcher.
