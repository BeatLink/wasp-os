# NeoTime

NeoTime is a fork of [wasp-os](https://github.com/wasp-os/wasp-os), a MicroPython
operating system for smartwatches such as the PineTime.

Its goal is to combine the features and apps of both
[InfiniTime](https://github.com/InfiniTimeOrg/InfiniTime) and wasp-os in one
firmware: wasp-os as the base, with InfiniTime's apps, watch faces and
functionality brought across.

The original wasp-os documentation is in [README.rst](README.rst).

## Status

Early work in progress. Nothing here is ready to flash to a watch yet.
